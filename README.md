# Java Quiz Application

A simple Java quiz application built with **Java Swing**. Users can choose a topic, answer multiple-choice questions, and see their score at the end.

## Features

* Choose from different Java topics
* Multiple-choice questions
* Automatic score calculation
* Simple graphical interface
* Questions loaded from a text file

## Topics

* Arrays
* Loops
* Conditional Statements
* Functions/Methods
* Object-Oriented Programming Basics

## Technologies

* Java
* Java Swing
* File I/O
* ArrayList
* Eclipse
* Git/GitHub

## How to Run

1. Open the project in Eclipse or another Java IDE.
2. Make sure `quiz.txt` is in the correct project folder.
3. Run `QuizApplication.java`.

**Note:** The application uses Java Swing, so it needs a graphical desktop environment to run.

## Purpose

This project was created to practice Java programming, GUI development, file handling, and object-oriented programming.
